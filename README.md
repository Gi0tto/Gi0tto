I'm an Agentic AI Engineer at AUTODOC, based in Chișinău, Moldova. I build production AI systems for SEO and content teams: multi-agent workflows in n8n, MCP servers that connect agents to internal services, RAG pipelines, and small FastAPI services shipped with Docker.

I got here the long way round. I started in Customer Care, moved into conversational AI and co-designed "Dan", a multilingual assistant that runs in 22 languages across 27 countries, and now I work on agents. That path left me with one habit: I care less about whether a demo works than about whether the thing still works on a Tuesday six months later, and whether anyone notices when it doesn't.

Lately I'm most interested in web data extraction that doesn't need a model to read the page.

### Featured

**[sluicer](https://github.com/Gi0tto/sluicer)** · turn a web page into structured data. No model, no API key, no bill.
It reads what a page already declares (JSON-LD, microdata, RDFa, OpenGraph), merges it into one record with the source of every value, and learns extractors from a few pages of a template that fail loudly when the site changes. Ships a CLI and an MCP server. [Docs and scoreboard](https://gi0tto.github.io/sluicer/) · `pip install sluicer`
